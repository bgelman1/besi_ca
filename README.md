cepr_analysis: using 5 year aggregates of CEPR CPS ORG Uniform Extracts Version 2.5 data, calculates union wage premium for construction, non construction, CA, and non-CA workers over time. 

data source: https://ceprdata.org/cps-uniform-data-extracts/cps-outgoing-rotation-group/cps-org-data/
Center for Economic and Policy Research. 2020. CPS ORG Uniform Extracts, Version 2.5. Washington, DC.

To access the underlying data visit https://ceprdata.org/cps-uniform-data-extracts/cps-outgoing-rotation-group/
